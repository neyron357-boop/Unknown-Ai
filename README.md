# UNKNOWN: ASCENSION

Кинематографичный экшен 18+ для телефона. Ты — аномалия в мире, которым правят сверхлюди.
Ты слабее физически, но видишь закономерности: читаешь атаки до того, как они случились,
запоминаешь слабые точки и побеждаешь стратегией.

Бой — **ритм-дуэль** под phonk: враг бьёт в такт музыки, ты отбиваешь в такт. Когнитивные навыки работают
**внутри действия**: память на ритм позволяет отбиваться вслепую, внимание отличает настоящего врага от фантомов,
счёт в уме решает силу удара, зрительная память открывает финишер. Это игра, а не тренажёр и не медицинский продукт.

> Статус: **PHASE 1 · v2** — миссия «ПРОБУЖДЕНИЕ» переделана в ритм-дуэль из четырёх разных раундов
> (после отзыва «скучно, однотипно, дёшево выглядит»). Играется от начала до конца.

## Быстрый старт (Windows)

1. Установите **Node.js 22 LTS** или новее (нужен ≥ 22.12): https://nodejs.org
2. В терминале (PowerShell):
   ```powershell
   git clone https://github.com/neyron357-boop/Unknown-Ai.git
   cd Unknown-Ai
   npm install
   copy .env.example .env    # по желанию: вписать GEMINI_API_KEY
   npm run dev
   ```
3. Откройте http://localhost:5173. На ПК: `←/→` или `A/D` — рывок, `Пробел`/`↓` — щит, `1–6` — слабые точки.

Без ключа Gemini всё работает: ИИ-наставник переходит в **деморежим** с заготовленными репликами.

## Как открыть на iPhone

**Вариант A — быстро, по Wi-Fi (для игры и отладки):**

1. ПК и iPhone в одной сети Wi-Fi.
2. `npm run dev:lan` — Vite напечатает адрес вида `http://192.168.x.x:5173`.
3. Откройте его в Safari на iPhone. Если Windows спросит про брандмауэр — разрешите Node.js в частных сетях.

Звук включается первым касанием. **Переключатель «Без звука» на iPhone глушит Web Audio** — переведите его в режим звонка.

**Вариант B — установка на главный экран (PWA, офлайн):** iOS требует HTTPS.

```powershell
npm run build
npm start                                        # сервер игры + API на http://localhost:8787
npx cloudflared tunnel --url http://localhost:8787   # бесплатный HTTPS-туннель, даст https://…trycloudflare.com
```

Откройте HTTPS-адрес в Safari → «Поделиться» → «На экран „Домой“». Игра запускается во весь экран и
после первого открытия работает без сети (кроме комментариев Gemini). Для постоянного адреса
подойдёт любой хостинг Node.js (Render, Railway, Fly.io): команда сборки `npm run build`, запуска `npm start`.

## Gemini — ИИ-наставник ЭХО

```env
GEMINI_API_KEY=ваш_ключ          # https://aistudio.google.com/apikey
GEMINI_MODEL=gemini-3.5-flash-lite  # можно сменить без правки кода
AI_RATE_LIMIT_PER_MIN=12
```

- Ключ читается **только сервером** (`server/`), в клиентский бандл не попадает; к Google он уходит в заголовке, не в URL.
- `POST /api/ai/mentor` принимает только числовую сводку забега и enum-значения (валидация `zod`, лимит 16 КБ) —
  произвольный текст от клиента в промпт не попадает.
- Ограничение частоты по IP (token bucket), таймаут 8 с, любые сбои → локальная реплика.
- Gemini **только комментирует** факты, посчитанные игрой. Он не решает исход ходов, не считает очки и не меняет правила.
- Названия моделей у Google меняются часто: если ответы не приходят, проверьте `GEMINI_MODEL` по
  [списку моделей](https://ai.google.dev/gemini-api/docs/models). Статус виден в «Настройки → ИИ-наставник».

## Миссия 01 — «ПРОБУЖДЕНИЕ» (ритм-дуэль)

Дуэль на мокрой крыше под луной, вид сбоку. Всё стоит на сетке бита: ВЕРДИКТ замахивается и бьёт ровно в доли такта,
музыка ведёт бой. Четыре раунда — четыре разные механики, свой темп, свой цвет неба и своя музыкальная секция.

| Раунд | Что происходит | Навык |
|---|---|---|
| 1 ТАКТ | ВЕРДИКТ повторяет одну серию ударов. Сначала тип удара виден заранее, потом всё позже, последний круг — **вслепую** | ритм, рабочая память |
| 2 ФАНТОМЫ | Три фигуры, бьёт одна. Настоящая отбрасывает отражение и тень; фантомы сначала бледные, потом почти не отличаются. Удар фантома надо **пропустить** | контроль импульса, внимание |
| 3 ПЕРЕГРУЗКА | Две сферы энергии (+n, ×n, −n) — выбери ту, что даст **больше**: свайп или тап в её сторону. Затем вся энергия уходит в столкновение клинков на 4 бита | счёт в уме под давлением |
| 4 ВОЗНЕСЕНИЕ | Финальная защита, потом время замедляется и на теле врага по очереди вспыхивают руны — повтори порядок на круге рун. Финишер-иайдо падает на дроп трека | зрительная память |

**Ответы на удары (правило одно на всю игру):**

| Удар | Как выглядит | Ответ |
|---|---|---|
| средний ◆ | горизонтальный замах | **тап** — парирование |
| высокий ▼ | замах сверху | **свайп вниз** — пригнуться |
| низкий ▲ | подсечка | **свайп вверх** — прыжок |

- После каждой серии — окно атаки на 3 бита: тап **в бит** (±90 мс) = крит. Комбо умножает очки, а музыка
  с ростом комбо добавляет слои (5 уровней «хайпа»).
- Между раундами — выбор 1 из 3 сил (резонанс, предвидение, второе дыхание, холодный ум, ритм крови и др.);
  если не выбрать за 15 с, сила выбирается сама.
- Ошибки стоят целостности; при нуле — «перезагрузка» на 4 бита и продолжение, поражения нет.
- Оценка S/A/B/C по открытой формуле: защита 55 %, удары в бит 10 %, выбор энергии 15 %, руны 20 %.

**Режимы:** ИСКРА — 118→140 BPM; ПОТОК — длиннее серии и больше рун; ТИШИНА — 96→114 BPM, шире окна, тип удара виден раньше.

**Адаптация (UNKNOWN Cognitive Engine):** правило прозрачно и видно на экране «Прогресс». По последним трём забегам
в режиме: средняя оценка < 0,55 или перезагрузки → темп медленнее и окна шире на один шаг (5 %); оценка ≥ 0,88 без
перезагрузок → на шаг строже. Один шаг за забег, диапазон 0,85–1,25 — сложность никогда не прыгает.
Никаких медицинских или эмоциональных выводов.

## Доступность и комфорт

Настройки: громкость музыки/эффектов и общий предел, вспышки (выкл/мягко/полно, не чаще ~3 в секунду),
тряска камеры, «меньше движения» (учитывается `prefers-reduced-motion`), плотность частиц и свечения,
подсказки, комментарии ЭХО, вибрация (только Android — Safari не даёт API), язык RU/EN.
Пауза автоматически при сворачивании, блокировке экрана или потере фокуса; на старте каждого раунда сохраняется
чекпоинт — миссию можно продолжить со следующего раунда (чекпоинт хранится 7 дней). Ни уведомлений, ни серий дней, ни штрафов за пропуски.

## Приватность и научная честность

- Вся статистика хранится только на устройстве (IndexedDB). «Прогресс → Удалить все данные» стирает всё.
- На сервер уходит только числовая сводка забега и только для комментария ЭХО (отключается в настройках).
- Игра измеряет результаты конкретных игровых задач. Она не повышает IQ, не формирует «фотографическую память»,
  не лечит СДВГ и не заменяет лечение. Перенос навыков в жизнь — отдельная задача Phase 5.

## Архитектура

```
src/
  game/core/        чистый TypeScript, без Phaser и DOM — все правила и тайминги
    director.ts       DuelDirector: детерминированный ритм-директор (сетка бита, события + update(dt), ввод с метками времени)
    plan.ts           тюнинг режимов, серии ударов, фантомы, сферы энергии, руны, предложения сил
    metrics.ts random.ts types.ts
  game/input/       распознавание жестов: тап и свайпы ↑ ↓ ← → с временем касания (а не обработки кадра)
  game/scene/       Phaser 3: DuelScene, скелетные силуэты (rig/poses/Fighter: кинематика, ткань, следы клинка),
                    фон (луна, город, дождь, молнии, отражения), ритм-дорожка, сферы, круг рун, эффекты
  game/MissionSession.ts  связка: правила ↔ HUD ↔ звук ↔ ввод ↔ пауза ↔ чекпоинты
  audio/            Web Audio: синтезированный phonk, секции под каждый раунд, слои по комбо, дроп; дирижирует директор
  cognitive/        Cognitive Engine: адаптация, профиль, поиск повторяющихся ошибок, IndexedDB
  ai/               клиент наставника (всегда с локальным запасным ответом)
  ui/               React-экраны и HUD (Tailwind)
  state/ i18n/
server/             Express: /api/ai/*, раздача собранной PWA, rate limit, zod-валидация
shared/             общие типы и деморежим наставника (клиент + сервер)
tests/  e2e/
```

Принцип: **правила отдельно от отрисовки.** Phaser и React только слушают события директора и передают намерения
игрока. Поэтому миссию можно целиком прогнать в тестах за миллисекунды, а позже перенести логику в нативную оболочку
(Capacitor и т. п.) без переписывания.

Компромиссы: Phaser 3.90 (как запрошено); персонажи — процедурные силуэты на скелете (стиль «тень + неоновый контур»),
а не нарисованные спрайты: это даёт плавную анимацию любых поз, мгновенную загрузку и офлайн, но это стилизация,
а не иллюстрации художника; музыка — оригинальный синтезированный phonk, а не студийный трек; круг рун и сферы — в нижней
половине экрана, чтобы до них дотягивался большой палец одной руки.

## Отчёт: PHASE 1 · v2

**Что изменилось после отзыва**

- Вместо одной повторяющейся арены — ритм-дуэль из 4 раундов с разными механиками (такт вслепую, фантомы, счёт энергии,
  руны), разным темпом, цветом неба и музыкой. Между раундами — выбор силы, меняющий следующий раунд.
- Персонажи: скелетная анимация (герой с катаной, плащом, волосами и шарфом; ВЕРДИКТ с тесаком, плащом, нимбом),
  позы под каждый тип удара, следы клинка, импакт-кадры в стиле манги, hit-stop, замедление, отражения в мокром полу.
- Музыка дирижирует боем: удары врага стоят на долях, слои добавляются с комбо, у каждого раунда своя секция, финишер — на дропе.
- Обучение без текста: подсказка жеста над нотой на дорожке, исчезает по мере игры.

**Проверено**

- Typecheck клиента и сервера; юнит-тесты (`npm test`) — ритм-директор, полные симуляции для бездействующего,
  идеального и «жмущего всё подряд» игрока во всех режимах, жесты, адаптация, IndexedDB, контракт ИИ, сервер.
- e2e в мобильном Chromium (iPhone-размер): реальные жесты на арене, полная дуэль до экрана «Эволюция»,
  выбор силы тапом, «Прогресс», без ошибок в консоли.
- Визуально по скриншотам каждого раунда, карточек сил, финишера и итогов.
- Длительность по симуляциям: ≈ 1,8 мин игры в ИСКРЕ, ≈ 2,3 мин в ПОТОКЕ, ≈ 2 мин в ТИШИНЕ; с выбором сил и итогами
  сессия ≈ 3 мин. Это короче, чем 3–5 мин из ТЗ, — сознательно: короткий плотный забег + «Ещё раз».

**Что не работает или не проверено**

- Не проверено на настоящем iPhone и в Safari/WebKit — только эмуляция в Chromium. FPS на iPhone 12 не замерен
  (отражения и фантомы рисуются через render texture — на слабых устройствах это первое, что стоит упростить).
- Звук проверен программно, но не на слух — в облачной среде нет вывода звука. Синхронизация бита с изображением
  требует проверки на устройстве с наушниками (Bluetooth добавляет задержку; калибровки пока нет).
- Живой режим Gemini проверен на заглушках, с реальным ключом — нет.
- Вибрация недоступна в Safari на iOS (ограничение платформы).
- CHESS MENTOR не начат и не показан в меню (по плану — Phase 3).
