# UNKNOWN: ASCENSION

Кинематографичный нуар-экшен 18+ для телефона. Ты — клинок. Каждый свайп — удар в сторону врага,
каждый удар — в бит трека. Крыши под кровавой луной, падение с небоскрёба, бой на крыше поезда в тоннелях
и дуэль с палачом ВЕРДИКТОМ в храме. Много крови, расчленение, замедления, манга-звуки на весь экран,
голоса персонажей и аномалии, которые ломают «четвёртую стену».

Внимание, память на серии и контроль импульса работают **внутри боя**: финты нельзя бить, серии босса
повторяются, казнь нужно повторить по памяти. Это игра, а не тренажёр и не медицинский продукт.

> Статус: **PHASE 1 · v3** — после отзыва «слишком по-детски, тап-тап — скучно» игра пересобрана с нуля:
> новая механика (свайп-удары по волнам на сетке бита), новые персонажи и мир, процедурный phonk,
> озвучка Gemini TTS и живые реплики Gemini. Миссия «КРОВАВАЯ ЛУНА» играется от начала до конца.

## Быстрый старт (Windows)

1. Установите **Node.js 22 LTS** или новее (нужен ≥ 22.12): https://nodejs.org
2. В терминале (PowerShell):
   ```powershell
   git clone https://github.com/neyron357-boop/Unknown-Ai.git
   cd Unknown-Ai
   npm install
   copy .env.example .env    # по желанию: вписать GEMINI_API_KEY
   npm run dev
   ```
3. Откройте http://localhost:5173. На ПК удары — стрелки или `W A S D`.

Без ключа Gemini всё работает: голоса играют из готового банка, реплики ЭХО и ВЕРДИКТА — заготовленные.

## Как открыть на iPhone

**Вариант A — быстро, по Wi-Fi:** ПК и iPhone в одной сети, `npm run dev:lan`, откройте напечатанный адрес
`http://192.168.x.x:5173` в Safari (брандмауэр Windows: разрешить Node.js в частных сетях).

Звук включается первым касанием. **Переключатель «Без звука» на iPhone не глушит игру** (используется аудиосессия
«playback»), но громкость — кнопками телефона. Лучше в проводных наушниках: Bluetooth добавляет задержку.

**Вариант B — установка на главный экран (PWA, офлайн):** iOS требует HTTPS.

```powershell
npm run build
npm start                                            # игра + API на http://localhost:8787
npx cloudflared tunnel --url http://localhost:8787   # бесплатный HTTPS-туннель → https://…trycloudflare.com
```

Safari → «Поделиться» → «На экран „Домой“». После первого открытия игра, музыка и банк голосов работают без сети
(без сети нет только живых реплик Gemini). Постоянный адрес — любой Node.js-хостинг (Render, Railway, Fly.io):
сборка `npm run build`, запуск `npm start`.

## Управление

| Угроза | Как выглядит | Ответ |
|---|---|---|
| враг слева / справа | бежит к герою, на замахе контур вспыхивает красным | **свайп в его сторону** |
| громила | броня, большой молот | два свайпа подряд, в соседние доли |
| ловкач | после первого удара перескакивает на другую сторону | режь туда, где он оказался |
| обманщик | **белые глаза — финт, не бей**; красные — настоящая атака | выдержка |
| прыгун | атакует сверху | **свайп вверх** |
| ползун | атакует снизу | **свайп вниз** |
| стрелок | стреляет из глубины кадра | свайп в его сторону — пуля летит обратно |
| Мясник (мини-босс) | бензопила, серия ударов | держать бит |
| ВЕРДИКТ: высокий / низкий / выпад | замах сверху / подсечка / укол | **вверх / вниз / к нему**; финт — не трогать |

Зигзаг без отрыва пальца (влево-вправо-влево) засчитывается как серия отдельных ударов. Касание без свайпа не атакует.

## Миссия «КРОВАВАЯ ЛУНА»

Четыре акта, ≈ 2,2 мин в ИСКРЕ (128 BPM), ≈ 2,8 мин в ПОТОКЕ (120 BPM, длиннее волны и дуэль),
≈ 2,9 мин в ТИШИНЕ (100 BPM, окна шире, без восьмых долей).

| Акт | Что происходит |
|---|---|
| I · КРЫША | волны рядовых и громил под дождём, первый камео-союзник, дроп трека с плотной волной |
| II · ПАДЕНИЕ | крыша обрушивается — бой в падении вдоль фасада небоскрёба |
| III · ПОЕЗД | крыша поезда, тоннели с лампами, ловкачи, стрелки, обманщики; мини-босс Мясник |
| IV · ХРАМ | ВЕРДИКТ: дуэль (его серии повторяются — запоминай), ярость, слом стойки и **казнь**: он показывает линии ударов, ты повторяешь их в бит |

- **Всё на сетке бита.** Враги приходят так, что удар ложится на долю; окна попадания: идеально ±65 мс,
  чисто −140/+125 мс (ТИШИНА: ±85, −180/+160).
- **Ярость → ЖАЖДА КРОВИ:** точные удары заполняют шкалу; полная — 8 долей двойных очков и самых жестоких убийств.
- **Перезагрузка вместо смерти:** при нуле здоровья — 4 доли «перезагрузки сердца» и бой продолжается.
- **Камео:** Чистильщик (киллер), Лиса (куноити), Безымянный Ронин помогают на одном фланге; Мясник — враг.
- **Аномалии:** молния, зеркало (мир отражается — свайпай туда, куда видишь), луна открывает глаз, кровавый дождь,
  глитч, шёпот ВЕРДИКТА игроку «по ту сторону экрана», разрез интерфейса, фальшивый «вылет» игры, остановка времени,
  манга-панели, затемнение.
- **Чекпоинты:** начало актов I и III и выход босса (хранятся 7 дней).

**Режимы и адаптация.** По последним трём боям в режиме: оценка < 0,55 или перезагрузки → на шаг легче
(темп ниже, окна шире, меньше врагов), оценка ≥ 0,88 без перезагрузок → на шаг строже. Шаг 5 %, диапазон 0,85–1,25,
правило и текущее состояние видны на экране «Прогресс». Никаких медицинских или эмоциональных выводов.

## Gemini: голоса и живые реплики

```env
GEMINI_API_KEY=ваш_ключ        # https://aistudio.google.com/apikey — только в .env на сервере
```

| Что | Как |
|---|---|
| Банк голосов (≈ 90 реплик: рассказчик, ВЕРДИКТ, ЭХО, камео, враги, чанты в музыку) | заранее сгенерирован Gemini TTS (`npm run voice:gen`), лежит в `public/voice/` как MP3; в игре — низкие «басовые» эффекты, реверб, дакинг музыки |
| Эпизод перед боем: название, вход ВЕРДИКТА, 3 насмешки, шёпот, подсказка ЭХО | `POST /api/ai/episode` — по твоим слабостям (числа и enum: слабый тип врага, ранние/поздние удары, финты, казнь) |
| Живой голос ВЕРДИКТА для входа и шёпота | `POST /api/ai/voice` — Gemini TTS, кеш на сервере |
| Разбор боя ЭХО | `POST /api/ai/mentor` — 2 фразы по фактам боя |
| Проверка качества озвучки | генератор расшифровывает каждый клип моделью Gemini и перегенерирует неразборчивые |

- Ключ читается **только сервером**, в клиент и в репозиторий не попадает. Клиент шлёт только числа и enum-значения
  (валидация `zod`), лимиты по IP, таймауты, кеш, любые сбои → банк голосов и заготовленные реплики.
- Gemini **только говорит и комментирует**. Правила, урон, очки и исход боя считает игра.
- Бесплатный уровень ключа: ≈ 10 TTS-запросов в сутки на модель (сброс в 00:00 UTC), генерация музыки (Lyria),
  картинок и видео недоступна (квота 0) — поэтому музыка и персонажи процедурные. Подробно: [`docs/voice.md`](docs/voice.md).

## Музыка и камео — что сделано вместо чужих хитов и чужих персонажей

- Треки из чартов/TikTok и чужие персонажи (с голосами актёров) защищены авторским правом — в игру их встроить нельзя.
  Вместо них **оригинальный процедурный phonk** в трендовых стилях (дрифт-фонк, «бразильский» фонк с ковбеллом,
  hyper, slowed) — секции под каждый акт, дропы, слои по комбо, чанты из банка голосов, замедление и «tape stop»
  на аномалиях. Все удары врагов стоят на долях трека.
- Камео — **оригинальные архетипы** (киллер в костюме, куноити, ронин, мясник с бензопилой) с собственными голосами,
  без копирования внешности и голосов реальных актёров.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Vite (5173) + API (8787) с автоперезагрузкой |
| `npm run dev:lan` | то же, доступно с телефона в локальной сети |
| `npm test` | Vitest: директор боя и полные симуляции, звук (DSP, паттерны, тайминг), адаптация, IndexedDB, сервер, ИИ-контракты |
| `npm run e2e` | мобильный Chromium: 18+ → бой в два касания → реальные свайпы → бот проходит всю миссию → итоги → прогресс (нужен `npm run dev`) |
| `npm run typecheck` | TypeScript клиента и сервера |
| `npm run build` | typecheck → PWA в `dist/` → сервер в `dist-server/` |
| `npm start` | production-сервер: игра + API на одном порту |
| `npm run build:artifact` | однофайловая сборка без сервера (голоса — рядом, в `voice/`) |
| `npm run voice:gen` | догенерировать/переозвучить банк голосов (нужен ключ) |
| `npm run audio:lab` | лаборатория звука: прослушать секции, стили и SFX |

Отладочные страницы (только dev): `/?battle3&seg=trainA` — бой с автопилотом с любого сегмента,
`/?gallery3=cast|hero|boss|gore` — галерея персонажей и расчленения.

## Доступность и комфорт

Предупреждение 18+ при первом запуске. Настройки: кровь (много / меньше / выкл), вспышки, тряска, «меньше движения»
(учитывается `prefers-reduced-motion`), частицы, громкость музыки/эффектов/голосов и общий предел, субтитры RU/EN,
подсказки при новом враге, ИИ-реплики, вибрация (только Android), язык. Пауза при сворачивании и блокировке экрана.
Ни уведомлений, ни серий дней, ни штрафов за пропуски.

## Приватность и честность

- Статистика хранится только на устройстве (IndexedDB); «Прогресс → Удалить все данные» стирает всё.
- На сервер уходит только числовая сводка (для реплик Gemini; отключается в настройках).
- Игра измеряет результаты игровых задач. Она не повышает IQ и не лечит СДВГ.

## Архитектура

```
src/
  game/v3/core/      чистый TypeScript: BattleDirector (сетка бита, волны, дуэль, казнь, ярость, аномалии, реплики),
                     chart.ts (сценарий миссии из seed/режима/сложности), metrics.ts — всё прогоняется в тестах
  game/v3/anatomy/   процедурные персонажи: скелет с IK, силуэты по мышечным профилям, контровой свет,
                     ткань (verlet), рэгдолл с расчленением
  game/v3/scene/     Phaser 3: BattleScene, миры актов, кровь и брызги, слова-звуки, аномалии, манга-панели
  game/v3/session/   BattleSession — правила ↔ ввод ↔ музыка ↔ голоса ↔ HUD ↔ пауза ↔ чекпоинты
  game/v3/input/     распознавание свайпов с временем движения пальца
  audio/v3/          процедурный phonk-движок (дирижирует директор), библиотека кровавых SFX
  voice/             банк голосов: реплики, VoiceManager (приоритеты, эффекты, субтитры), живые реплики
  cognitive/ ai/ ui/ state/ i18n/
server/              Express: /api/ai/* (episode, voice, mentor, status), раздача PWA, лимиты, zod
shared/              общие типы и заготовленные реплики (клиент + сервер)
scripts/voice/       генератор банка голосов (Gemini TTS → нарезка → ASR-проверка → ffmpeg)
```

Принцип: **правила отдельно от отрисовки.** Phaser и React только слушают события директора и передают свайпы.
