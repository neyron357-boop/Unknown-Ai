# UNKNOWN: ASCENSION

Кинематографичный экшен 18+ для телефона. Ты — аномалия в мире, которым правят сверхлюди.
Ты слабее физически, но видишь закономерности: читаешь атаки до того, как они случились,
запоминаешь слабые точки и побеждаешь стратегией.

Когнитивные навыки тренируются **внутри действия**: прогноз открывает контратаку, память решает
исход Ascension-удара, поспешное решение сбивает с ног. Это игра, а не тренажёр и не медицинский продукт.

> Статус: **PHASE 1 — Playable Foundation**. Миссия «ПРОБУЖДЕНИЕ» играется от начала до конца.

## Быстрый старт (Windows)

1. Установите **Node.js 22 LTS** или новее (нужен ≥ 22.12): https://nodejs.org
2. В терминале (PowerShell):
   ```powershell
   git clone https://github.com/neyron357-boop/Unknown-Ai.git
   cd Unknown-Ai
   npm install
   copy .env.example .env    # по желанию: вписать GEMINI_API_KEY
   npm run dev
   ```
3. Откройте http://localhost:5173. На ПК: `←/→` или `A/D` — рывок, `Пробел`/`↓` — щит, `1–6` — слабые точки.

Без ключа Gemini всё работает: ИИ-наставник переходит в **деморежим** с заготовленными репликами.

## Как открыть на iPhone

**Вариант A — быстро, по Wi-Fi (для игры и отладки):**

1. ПК и iPhone в одной сети Wi-Fi.
2. `npm run dev:lan` — Vite напечатает адрес вида `http://192.168.x.x:5173`.
3. Откройте его в Safari на iPhone. Если Windows спросит про брандмауэр — разрешите Node.js в частных сетях.

Звук включается первым касанием. **Переключатель «Без звука» на iPhone глушит Web Audio** — переведите его в режим звонка.

**Вариант B — установка на главный экран (PWA, офлайн):** iOS требует HTTPS.

```powershell
npm run build
npm start                                        # сервер игры + API на http://localhost:8787
npx cloudflared tunnel --url http://localhost:8787   # бесплатный HTTPS-туннель, даст https://…trycloudflare.com
```

Откройте HTTPS-адрес в Safari → «Поделиться» → «На экран „Домой“». Игра запускается во весь экран и
после первого открытия работает без сети (кроме комментариев Gemini). Для постоянного адреса
подойдёт любой хостинг Node.js (Render, Railway, Fly.io): команда сборки `npm run build`, запуска `npm start`.

## Gemini — ИИ-наставник ЭХО

```env
GEMINI_API_KEY=ваш_ключ          # https://aistudio.google.com/apikey
GEMINI_MODEL=gemini-3.5-flash-lite  # можно сменить без правки кода
AI_RATE_LIMIT_PER_MIN=12
```

- Ключ читается **только сервером** (`server/`), в клиентский бандл не попадает; к Google он уходит в заголовке, не в URL.
- `POST /api/ai/mentor` принимает только числовую сводку забега и enum-значения (валидация `zod`, лимит 16 КБ) —
  произвольный текст от клиента в промпт не попадает.
- Ограничение частоты по IP (token bucket), таймаут 8 с, любые сбои → локальная реплика.
- Gemini **только комментирует** факты, посчитанные игрой. Он не решает исход ходов, не считает очки и не меняет правила.
- Названия моделей у Google меняются часто: если ответы не приходят, проверьте `GEMINI_MODEL` по
  [списку моделей](https://ai.google.dev/gemini-api/docs/models). Статус виден в «Настройки → ИИ-наставник».

## Миссия 01 — «ПРОБУЖДЕНИЕ»

| Этап | Что происходит | Навыки |
|---|---|---|
| 01 Пробуждение | Герой собирается из света; три жеста учатся на ходу: свайп →, свайп ←, касание | — |
| 02 Первый контакт | ВЕРДИКТ показывает удары; первые три — медленно и с подсказкой жеста | распознавание сигналов, реакция |
| 03 Закономерность | Враг повторяет фиксированную серию. Действуй **в паузе до сигнала** — «ПРОЧТЕНО», контратака, аура ×3 | поиск закономерностей, прогноз, рабочая память |
| 04 Вознесение | При полной ауре успешная защита останавливает время. Слабые точки вспыхивают по очереди — бей в том же порядке. Bass drop, контратака. Затем ПЕРЕГРУЗКА: новый ритм и новый удар → второе Вознесение и финишер | зрительная память, гибкость, контроль импульса |
| 05 Эволюция | Точность, реакция, прогнозы, лучшее решение, комментарий ЭХО | — |

**Правила честные и неизменные внутри испытания:**

| Сигнал | Ответ |
|---|---|
| Красная зона слева (◣) | свайп **вправо** |
| Красная зона справа (◢) | свайп **влево** |
| Кольца по всему полу (▼) | **касание** — щит |
| Белый луч по центру (│) | свайп в **любую** сторону, щит не держит |

- Прогноз в паузе: верный → «ПРОЧТЕНО»; неверный → герой сбит на 0,36 с, потом можно исправиться.
- Первая реакция во время сигнала окончательна (цена поспешности).
- Ошибки стоят целостности; при нуле — «перезагрузка» и продолжение, а не поражение.
- Если аура долго не набирается, ЭХО помогает — миссия проходима всегда (это проверено тестами для бездействующего игрока).

**Режимы:** ИСКРА — быстрые короткие серии; ПОТОК — длинные серии на устойчивое внимание; ТИШИНА — спокойный темп и широкие окна.

**Адаптация (UNKNOWN Cognitive Engine):** правило прозрачно и видно на экране «Прогресс». По последним трём
забегам в режиме: точность < 60 % или перезагрузки → сигналы длиннее на 5 %; точность ≥ 90 %, реакция ≤ 420 мс
и без помощи → короче на 5 %. Один шаг за забег, диапазон 0,85–1,25. Никаких медицинских или эмоциональных выводов.

## Доступность и комфорт

Настройки: громкость музыки/эффектов и общий предел, вспышки (выкл/мягко/полно, не чаще ~3 в секунду),
тряска камеры, «меньше движения» (учитывается `prefers-reduced-motion`), плотность частиц и свечения,
подсказки, комментарии ЭХО, вибрация (только Android — Safari не даёт API), язык RU/EN.
Пауза автоматически при сворачивании, блокировке экрана или потере фокуса; прогресс этапа сохраняется,
миссию можно продолжить с этапа 3 или 4 (чекпоинт хранится 7 дней). Ни уведомлений, ни серий дней, ни штрафов за пропуски.

## Приватность и научная честность

- Вся статистика хранится только на устройстве (IndexedDB). «Прогресс → Удалить все данные» стирает всё.
- На сервер уходит только числовая сводка забега и только для комментария ЭХО (отключается в настройках).
- Игра измеряет результаты конкретных игровых задач. Она не повышает IQ, не формирует «фотографическую память»,
  не лечит СДВГ и не заменяет лечение. Перенос навыков в жизнь — отдельная задача Phase 5.

## Архитектура

```
src/
  game/core/        чистый TypeScript, без Phaser и DOM — все правила и тайминги
    director.ts       MissionDirector: детерминированная машина состояний миссии (события + update(dt))
    missionConfig.ts  тюнинг режимов, сценарий обучения, узлы слабых точек
    rules.ts metrics.ts random.ts types.ts
  game/input/       распознавание жестов (свайп / касание / удержание / тап по точке)
  game/scene/       Phaser 3: арена, ВЕРДИКТ, герой, процедурные неоновые текстуры, эффекты
  game/MissionSession.ts  связка: правила ↔ HUD ↔ звук ↔ ввод ↔ пауза ↔ чекпоинты
  audio/            Web Audio: синтезированный phonk-луп по слоям интенсивности, slow-mo, drop, SFX
  cognitive/        Cognitive Engine: адаптация, профиль, поиск повторяющихся ошибок, IndexedDB
  ai/               клиент наставника (всегда с локальным запасным ответом)
  ui/               React-экраны и HUD (Tailwind)
  state/ i18n/
server/             Express: /api/ai/*, раздача собранной PWA, rate limit, zod-валидация
shared/             общие типы и деморежим наставника (клиент + сервер)
tests/  e2e/
```

Принцип: **правила отдельно от отрисовки.** Phaser и React только слушают события директора и передают намерения
игрока. Поэтому миссию можно целиком прогнать в тестах за миллисекунды, а позже перенести логику в нативную оболочку
(Capacitor и т. п.) без переписывания.

Компромиссы: Phaser 3.90 (как запрошено; Phaser 4 уже вышел — миграция возможна позже); графика процедурная
(Canvas2D-неон → текстуры), без внешних ассетов — мгновенная загрузка и офлайн, но это стилизация, а не иллюстрации;
музыка — оригинальный синтезированный луп, а не студийный трек; линза Вознесения вынесена в нижнюю половину экрана,
чтобы до неё дотягивался большой палец одной руки.

## Отчёт по PHASE 1

**Реализовано и проверено**

- Проект: TypeScript, React 19, Vite 8, Phaser 3.90, Tailwind 4, Zustand, Web Audio, Express, IndexedDB, Vitest, PWA.
- Миссия «Пробуждение» — все пять этапов, четыре типа атак, прогноз, ошибки с последствиями без поражения, два Вознесения, финишер.
- Управление одной рукой: свайпы, касание, удержание; клавиатура на ПК.
- Кинематографичные эффекты: slow-mo, hit-stop, вспышки, тряска, частицы, ударные волны, разрушение врага.
- Звук: синтезированный phonk (808, каубелл, хэты), слои по напряжению, фильтр slow-mo, bass drop, звуковые сигналы атак со стереопанорамой; звук только после касания.
- Экран «Эволюция», экран «Прогресс» (графики, разбор по этапам и типам атак, правило адаптации), удаление данных.
- Серверный Gemini Service с деморежимом, валидацией, лимитами и таймаутами.
- Настройки доступности, RU/EN, пауза при уходе в фон, чекпоинты, офлайн-режим PWA.
- Проверки: 48 юнит-тестов; e2e — бот проходит миссию в мобильном Chromium (iPhone-размер); вручную проверены пауза,
  возобновление, чекпоинт после перезагрузки, офлайн-запуск production-сборки, отсутствие ошибок в консоли.
- Длительность по симуляциям правил: ≈ 2,2–2,7 мин при уверенной игре с прогнозами, ≈ 2,7–3,3 мин только на реакции,
  до ≈ 4,5 мин если почти не действовать (миссия всё равно завершается). Первое прохождение у живого игрока, вероятно,
  ближе к 3–4 мин — это нужно проверить на реальных забегах.

**Что ещё не работает или не проверено**

- Не проверено на настоящем iPhone и в Safari/WebKit — только эмуляция в Chromium. Производительность на iPhone 12 не замерена.
- Звук проверен программно (контекст запущен, все эффекты без ошибок), но на слух — нет: в облачной среде нет вывода звука.
- Живой режим Gemini проверен на заглушках, с реальным ключом — нет. Имя модели по умолчанию может потребовать замены.
- Вибрация недоступна в Safari на iOS (ограничение платформы).
- CHESS MENTOR не начат и не показан в меню (по плану — Phase 3).
- Gemini пока только подводит итог забега; диалоги персонажей и генерация сцен — Phase 2.

**Следующий этап — PHASE 2: AI Evolution**

Живые диалоги с персонажами через Gemini (с тем же принципом «ИИ говорит — правила считают»),
персональные испытания из белого списка, более тонкая адаптация по типам атак, расширенная статистика,
калибровка прогнозов (оценка уверенности → сравнение с фактом).
